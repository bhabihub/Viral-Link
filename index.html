Ad setup: Google IMA test ad tag is configured. Test ads do not earn money.

ভিডিও লিংক বদলাবেন?

আপনার MP4 ফাইলের সরাসরি HTTPS URL নিচে বসিয়ে Apply চাপুন। URL-টি যেন ব্রাউজারে সরাসরি ভিডিও চালায় এবং CORS/hosting অনুমতি থাকে।

বিজ্ঞাপন সম্পর্কে জরুরি কথা

এই ফাইলে Google IMA-এর অফিসিয়াল sample/test ad tag ব্যবহার করা হয়েছে শুধু integration পরীক্ষা করার জন্য। এটি বাস্তব আয়ের বিজ্ঞাপন নয়। আসল বিজ্ঞাপনের জন্য আপনার অনুমোদিত ad server / Google Ad Manager থেকে পাওয়া নিজের VAST ad tag URL বসাতে হবে। ভুয়া ad tag বা অন্যের publisher ID ব্যবহার করবেন না।

Ad না এলে সাধারণত test inventory/network, browser ad blocker, domain setup বা ad tag-এর কারণে হতে পারে। কোডটি ad unavailable হলে ভিডিও চালানোর চেষ্টা করবে।
